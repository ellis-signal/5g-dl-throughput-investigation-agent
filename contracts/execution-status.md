# 执行状态合同

- `PASS`：指定的 verifier / audit 已真实执行，且退出码 0，返回结果通过。
- `FAIL`：verifier / audit 已真实执行，但检测到错误（退出码 1）。
- `NOT_RUN`：工具未被执行、不可用、被禁用或没有轨迹证据。**不得宣称通过。**
- `UNVERIFIED`：计算已写出报告，尚未执行验证。这是原始 `report.json` 固定状态；**不要在报告里伪造 PASS**。

**验收要求**：`compute` 仅创建 `UNVERIFIED` 报告；`verify`/`audit` 返回独立 verdict，可通过 `--receipt` 写出验收凭据。仅凭 `report.json` 内容不能宣称已经审计。

**退出码**：0 正常，1 已执行但不通过，2 参数/输入/文件访问错误。恢复预算最多 2 次，原始数据不可改写。

**范围**：公式和数值一致性核验不证明真实无线环境满足 AWGN 模型。
