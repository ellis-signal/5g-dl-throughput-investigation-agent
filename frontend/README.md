# RAN 取证台 · 前端

5G 下行吞吐率根因调查台的界面原型。单页、零依赖、可直接双击打开。

```text
frontend/
├── index.html       结构（顶栏 / 三栏案卷 / 页脚）
├── style.css        主题与布局（全部颜色、字体集中在 :root 变量）
├── app.js           账本渲染器 + 交互（无框架、无构建）
├── ledger-data.js   离线回退账本（由 tools/embed_ledger.py 生成）
└── preview/         浏览器截图（desktop / tablet / mobile / audit / undetermined）
```

## 打开方式

**推荐：配合后端**（账本实时、可审计、可导出报告）

```bash
cd 3-repo
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
# 打开 http://127.0.0.1:8765/
```

**离线：直接双击** `index.html`。此时使用 `ledger-data.js` 里的同一份账本，
界面标注"内置账本（离线回退）"，审计按钮为本地占位回执，不代表真实 PASS。

## 设计方向

**控制室案卷**：近黑底 + 细网格 + 一条发光的琥珀侧线，读起来像一台正在运行的取证终端，
而不是一个通用后台。三个记忆点：

1. **置信度做成十段信号条**，按判定着色（成立=青绿 / 存疑=琥珀 / 否定=珊瑚）。
2. **PRB 利用率做成 40 格频谱带**，超过 85% 自动转为告警色。
3. **证据 ID 贯穿全页**：假设卡、账本、结论引用同一套 `EV-<小区>-<假设>-<检查>` 编号。

换风格只需改 `:root` 里的色板与三个字体变量，结构不用动：

| 变量 | 含义 |
|---|---|
| `--bg` / `--panel` / `--panel-2` | 底色与两级面板 |
| `--ok` / `--signal` / `--bad` | 成立 / 存疑 / 否定 |
| `--display` / `--sans` / `--mono` | 标题数字 / 正文 / 证据编号 |

## 页面结构

| 区域 | 内容 | 对应设计文档 |
|---|---|---|
| 顶栏 | 案件号、时间窗、审计状态与"运行独立审计" | 状态机 / 结论闸门 |
| 左栏 | 涉案小区、案卷信息、调查进度（5 步） | 调查流程 |
| 中栏 | Incident 头、5 个指标卡、4 张假设卡、证据账本 | 反证优先 / 证据账本 |
| 右栏 | 结论、置信度、排除项、缺失证据、处置建议、审计回执 | 结论与建议 |

## 交互

- **切换小区**：4 个小区对应覆盖 / 干扰 / 拥塞 / 无故障四种结局。
- **隐藏 PRB 字段**：把拥塞假设降级为"不可判定"，结论变为"证据不足"——
  演示"缺数据时不许猜"。
- **筛选证据**：全部 / 支持 / 否定。
- **运行独立审计**：`POST /api/audit` 后状态从 `UNVERIFIED` 变为 `PASS` 并出回执；切换小区后自动复位。
- **导出报告**：调用 `GET /api/report/{cell}` 打开 Markdown 报告（仅在线模式显示）。

## 数据与判定说明

页面**不做判定**，只渲染 `GET /api/ledger` 返回的账本（17 条证据 / 小区）。
结论、置信度、排除理由、缺失证据、建议全部来自后端；前端只负责组织与呈现。

`GET /api/cell/{id}?omit=prb` 用于演示"字段缺失时必须降级"：必要条件不可验证，
结论变成 `UNDETERMINED`，审计按钮同时禁用——这是产品规则，不是前端兜底逻辑。

`ledger-data.js` 与后端账本由同一个生成器产出（`tools/embed_ledger.py`），
因此离线打开看到的内容与在线一致，仅"审计"为本地占位。

## 验证记录

用 Chrome（headless）在 1440 / 1024 / 390 三个宽度检查：

- 页面无横向溢出（`scrollWidth == innerWidth`），无脚本报错、无资源 404；
- 关键文本无截断（指标卡、假设条件、排除项、建议逐项比对 `scrollWidth`）；
- 正文对比度 ≥ 5.1:1（AA），最小字号 9px 仅用于等宽标签；
- 在线模式：`GET /api/ledger` → 渲染 17 条证据；`POST /api/audit` → PASS（294 项检查）；
  审计回执哈希与 `/health` 的 `ledger_sha256` 一致；导出报告返回 `text/markdown`；
- 勾选"隐藏 PRB 字段"后结论变为"证据不足"、审计按钮禁用、缺失证据清单增加 1 项。

## 已知限制

- 离线模式（file://）的审计是本地占位回执，不代表真实 PASS，页面已标注。
- 未做空态 / 错误态页面：后端 4xx/5xx 目前只会静默回退到内置账本。
- 字体使用本机字体栈（Bahnschrift / Consolas / 思源黑体），未打包 woff2；
  若要在非 Windows 环境保持同一观感，需要补字体子集。
